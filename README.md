# 智能宠物行为识别与环境联动系统

一个面向家庭宠物照护场景的本地 Web Demo。系统把图片/摄像头行为分析、猫叫音频理解、环境传感器读取和喂食器控制整合到同一个 Gradio 界面中，便于进行功能验证、硬件联调和二次开发。

> 本仓库展示的是“宠物行为分析与照护联动应用”，不是通用视觉模型展示项目。图像检测模型是应用内部的一项实现依赖，最终产品功能以行为分析、风险提示和硬件联动为中心。

## 项目功能

| 模块 | 功能说明 |
| --- | --- |
| 图片行为分析 | 使用本地摄像头或上传图片，识别猫咪进食、饮水、玩耍、睡眠、如厕、呕吐等行为线索，并生成结构化检测结果。 |
| 宠物健康建议 | 可选调用阿里云 DashScope/Qwen 多模态接口，结合图片和检测结果输出行为判断、潜在风险与照护建议。 |
| 猫叫音频分析 | 支持上传或录制音频，直接分析猫叫情绪，不把猫叫强行当成人类语音转写；输出情绪标签、置信度、紧急程度和建议。 |
| CH340 硬件通信 | 通过 USB 转串口读取温度、湿度和食物重量，并测试原始 JSON 收发、舵机控制和报警控制。 |
| 本地联动控制 | 根据食物重量变化判断进食事件；在投放上限和温度阈值约束下，发送投喂舵机指令或高温报警指令。 |
| 本地会话管理 | 提供本地账号入口、会话日志、音频记录和报警记录；默认仅监听 `127.0.0.1`。 |

## 运行界面中的功能入口

1. **图片行为分析**：上传图片或使用摄像头，查看行为标注、检测详情、环境状态和分析报告。
2. **音频叫声分析**：上传或录制猫叫，查看音频元信息、情绪分析报告和本次会话记录。
3. **CH340 硬件收发测试**：刷新 COM 口、发送原始 JSON、读取温度/湿度、发送舵机角度。
4. **本地联动控制**：读取或填写传感器值，执行一次投喂/报警判断，并查看报警记录。

## 工作流程

```text
图片/摄像头 ──> 本地行为检测 ──> Qwen 多模态分析（可选） ──> 风险提示与照护建议
猫叫音频 ────> 音频元信息 ────> Qwen 音频理解（可选） ──> 情绪与紧急程度
CH340 传感器 ─> 温度/湿度/重量 ─> 本地规则判断 ──────────> 舵机投喂或报警
```

没有 DashScope API Key 时，图片检测、音频基础信息和硬件联调仍可用于本地功能验证；需要调用 Qwen 时再配置 API Key。

## 环境要求

- Windows 10/11（当前启动脚本按 Windows 本地 Demo 编写）
- Python 3.10–3.12，建议使用 Conda
- 浏览器：Chrome 或 Edge
- 可选：本机摄像头、USB 摄像头、CH340/CH341 串口模块及传感器/舵机
- 可选：阿里云百炼 DashScope API Key
- 图像行为分析需要一份与项目类别匹配的本地模型权重；权重文件默认被 `.gitignore` 排除，不随仓库提交

## 快速开始

### 1. 安装依赖

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

也可以使用仓库提供的 Conda 配置脚本：

```powershell
python setup_environment.py
```

该脚本会创建/复用 `yolocat` 环境并安装项目依赖。环境名称只是现有本地 Demo 的兼容命名，不代表项目展示内容。

### 2. 准备行为模型权重

项目不会把大体积权重和训练产物提交到 Git。请准备自己的行为识别权重，例如：

```text
runs/train/yolo-GDL/weights/best.pt
```

或在启动时显式指定：

```powershell
python .\pet_behavior_gradio_app.py --weight .\path\to\your\best.pt
```

权重中的类别名称应与训练数据一致；应用会将类别结果用于行为摘要和风险提示。仓库不对第三方权重、数据集或模型输出准确率作保证。

### 3. 启动应用

```powershell
python .\start_app.py
```

也可以直接启动：

```powershell
python .\pet_behavior_gradio_app.py
```

默认地址为 `http://127.0.0.1:7861/`。默认只监听本机，不启动公网映射；若端口被占用，应用会自动选择可用端口。

### 4. 首次进入与 API Key

首次进入页面时填写本地账号和密码即可创建本地 Demo 用户。DashScope API Key 是可选项：

- 配置 API Key：启用图片语义分析和猫叫情绪分析。
- 不配置 API Key：仍可使用本地检测、音频元信息、串口测试和联动规则验证。
- API Key 会按当前 Demo 逻辑保存到 `.gradio/pet_behavior_users.sqlite3`。该存储适合个人本机验证，不适合直接用于公网或多租户生产环境。

## CH340 硬件接入

默认串口参数：

| 参数 | 默认值 |
| --- | --- |
| 芯片 | CH340/CH341 |
| 波特率 | `115200` |
| 数据位/校验/停止位 | `8/N/1` |
| 编码 | UTF-8 |
| 帧结束 | `\\n` |
| 读取等待 | `0.5s` |

应用使用一行一个 JSON 的文本协议。常用命令示例：

```json
{"cmd":"temperature","action":"read"}
{"cmd":"humidity","action":"read"}
{"cmd":"weight","action":"read"}
{"cmd":"servo","id":1,"angle":90}
{"cmd":"alarm","level":"high"}
```

完整字段、返回格式、Arduino/ESP32 伪代码和联动逻辑见 [HARDWARE_SERIAL_PROTOCOL.md](HARDWARE_SERIAL_PROTOCOL.md)。

## 使用边界

本项目是研究、演示和工程联调工具，不是兽医诊断系统，也不是自动医疗设备。行为识别、情绪判断和风险提示可能出现误报或漏报；涉及呕吐、疼痛、呼吸异常、中毒、外伤或持续异常行为时，应由专业兽医确认。

自动投喂和报警联动必须在真实硬件接入前完成限位、断电、空载和异常返回测试。不要把示例阈值直接视为适用于所有宠物、粮食、设备或环境的安全参数。

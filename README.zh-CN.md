# 智能宠物行为识别与环境联动系统

本文件与仓库首页 [README.md](README.md) 保持一致，面向中文用户说明项目功能、环境配置、硬件联动和开源/商用边界。

## 项目定位

这是一个本地运行的宠物照护 Demo，将图片/摄像头行为分析、猫叫音频理解、环境传感器读取、投喂控制和报警联动整合到一个 Gradio 界面中，用于功能验证、算法联调和硬件原型开发。

主要能力包括：

- 图片或摄像头行为分析：进食、饮水、玩耍、睡眠、如厕、呕吐等行为线索。
- 可选的多模态分析：输出行为判断、潜在风险和照护建议。
- 猫叫音频理解：输出情绪标签、置信度、紧急程度和建议。
- CH340/CH341 串口通信：读取温度、湿度、重量，执行 JSON 收发和舵机控制。
- 本地联动控制：根据重量变化触发投喂，根据温度阈值触发报警。

## 快速开始

```powershell
python -m pip install -r requirements.txt
python .\start_app.py
```

默认访问 `http://127.0.0.1:7861/`。首次进入时创建本地账号；需要云端语义分析时再填写 DashScope API Key。图片行为分析需要通过 `--weight` 提供与项目类别匹配的本地权重：

```powershell
python .\pet_behavior_gradio_app.py --weight .\path\to\your\best.pt
```

默认训练输出目录为 `runs/train/pet_behavior/weights/best.pt`。Gradio 版本已限制在 `>=4.44.0,<6.0`。

## 公网和硬件

应用默认只监听本机，不会自动开启公网映射。远程演示前请显式使用 `--enable-frp`，配置服务端地址、端口和令牌，并完成 HTTPS、访问控制和日志审计。

串口功能需要 `pyserial`，默认使用 `115200`、`8/N/1`、UTF-8 和单行 JSON 协议。完整字段、返回格式和联动逻辑见 [HARDWARE_SERIAL_PROTOCOL.md](HARDWARE_SERIAL_PROTOCOL.md)。

## 安全边界

不要将 `.gradio/`、图片、音频、模型权重、数据集、日志、账号密码或 API Key 提交到公共仓库。行为识别和猫叫分析只能作为辅助信息，自动投喂必须配置限位、急停、断连保护和人工接管机制。
